🩺 DiagnoSense – AI-Powered Medical Assistant

DiagnoSense is an advanced AI-powered healthcare assistant built using Google Gemini, Streamlit, and modern UI components.
It can intelligently analyze symptoms, interpret PDF/JPG/PNG medical reports, visualize disease likelihood, and provide evidence-based medical insights.

⚠️ Disclaimer: This tool is for informational and educational purposes only and should not replace professional medical diagnosis or treatment.

🚀 Features
🔍 Symptoms Analyzer

Enter symptoms in natural language

AI generates:

Probable diseases

Risk levels

Follow-up questions

Medical advice

📄 Medical Report Analyzer

Upload PDF / JPG / JPEG / PNG medical reports

Automatically extracts content

AI generates:

Key findings

Disease analysis

Abnormal values

Recommendations

Whether urgent care is needed

📊 Disease Likelihood Visualization

Animated probability bars

Color coded:

🟥 High Risk

🟧 Medium Risk

🟩 Low Risk

⚙️ Additional Features

RAG-mode toggle (Evidence-based responses)

Medications input

Clean & modern UI

Fully optimized for GitHub deployment.
